# Contributing

Contributions, corrections, and new perspectives are welcome.

## What We're Looking For

- **Factual corrections** — if a protocol, tool, or capability description is outdated
- **New extensibility models** — emerging patterns we haven't covered
- **Real-world examples** — your experience composing MCP + Plugins + Skills
- **Platform updates** — new MCP servers, plugins, or skill ecosystems
- **Clarity improvements** — better diagrams, explanations, or examples

## How to Contribute

1. Fork this repository
2. Create a branch (`git checkout -b add-new-example`)
3. Make your edits to `blog/mcp-vs-plugins-vs-skills.md`
4. Submit a Pull Request with a clear description

## Guidelines

- Keep the tone **neutral and developer-focused**
- **Cite sources** for specific claims about protocols or tools
- Maintain the **three-layer model** structure for consistency
- Focus on **practical guidance** — when to use what

## Code of Conduct

Be respectful, constructive, and assume good intent.
